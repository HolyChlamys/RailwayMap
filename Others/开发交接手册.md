## 一、项目速览

中国铁路地图与中转路线规划系统。Maven 多模块 monorepo (Spring Boot 3.5.14 + Vue 3 + MapLibre GL JS)。

```
railway-api/         Spring Boot 入口 + REST Controller + Security/JWT
railway-service/     业务逻辑 (换乘图、矢量瓦片、搜索)
railway-data/        MyBatis-Plus Mapper + XML SQL (PostgreSQL/PostGIS)
railway-common/      Entity, DTO, Enum, 工具类
railway-batch/       Spring Batch 数据导入
railway-scripts/     Python 数据流水线 (抓取/清洗/导入)
railway-frontend/    Vue 3 SPA (Vite + TypeScript + Tailwind CSS 4)
```

**启动命令:**
```bash
# 基础设施
docker compose up -d db redis

# 后端 (:10010)
cd railway-api && mvn spring-boot:run -Dspring-boot.run.profiles=dev

# 前端 (:5173, proxy /api → :10010)
cd railway-frontend && npm run dev
```

## 四、易犯问题与注意事项

### Maven 构建
- `mvn install` 必须从**根目录** (`/home/chlamys/CODE/Project/RailwayMap`) 执行
- `mvn spring-boot:run -pl railway-api` 加载 `~/.m2/repository` 中的 JAR，**不是** `target/classes`
- 修改 `railway-service` 或 `railway-common` 后必须先 `mvn install -DskipTests` 才能被 `spring-boot:run` 加载
- 若修改未生效 → 检查 `mvn install` 是否成功 → 重启后端

### 前端编译
- `npm run build` 包含 `vue-tsc --noEmit` 类型检查
- 模板中 TypeScript 类型注解 **无效** (如 `v-for="(t: Train) in trains"` 会报错)

### 进程管理
- `pkill -f "spring-boot"` 会同时杀掉当前 shell (SIGTERM 传播)
- 使用 `ps aux | grep java | awk '{print $2}' | while read pid; do kill $pid; done` 替代
- 启动后台服务用 `run_in_background` 参数

### 文件编辑
- 文件可能被 Vite HMR 实时修改，Edit 工具前先 Read
- `sed` 修改 Vue 模板时注意转义 `'` 和正则特殊字符
- 不要用 sed 批量替换 `.type` → `.category`，会误伤其他类型

### 数据库
- `stations` 表的 `city` 字段为空 (GPKG 数据未填充)
- `train_stops.station_id` 为 NULL → 用 `station_name` 关联
- `train_stops.departTime` 大量 NULL → 数据源问题
- 有 `uq_station_osm_grid` 唯一约束，删除前需处理 FK (`train_stops.station_id`)

## 五、发现的不足

### 数据质量
- ❌ 车次经停站 `departTime` 大量 NULL → 显示 "-"
- ❌ 车站 `city` 字段为空 → 城市搜索/分类不完整
- ❌ 车次 stops 有重复记录 (同一站多条)
- ❌ 车次 `durationMin` 为 NULL (后端未计算)
- ❌ `train_crawler_playwright.py` 正则解析不完整

### 前端功能
- ❌ 地图点击站点标记无反应 (未接入交互)
- ❌ 图层切换后自定义铁路线可能丢失
- ❌ 经停车次模态窗仅加载 50 条 (北京站实际 198+)
- ❌ 图例和路线颜色未参考 `Others/样式.html` 设计稿

### 后端功能
- ❌ 换乘搜索 (`/api/transfer/search`) 全量图构建 + N+1 查询 (性能问题)
- ❌ 图节点使用站名而非 ID (同名站冲突)
- ❌ 无全局异常处理 (`@ControllerAdvice`)
- ❌ 无测试代码 (前后端均无)
- ❌ JWT 密钥/DB 密码硬编码
- ❌ `GeoUtils.wgs84ToGcj02()` 死代码
